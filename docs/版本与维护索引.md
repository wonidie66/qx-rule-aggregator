## 已知构建里程碑

- **V1.8**：74份上游分流源，20,938条已聚合规则。广告与 TikTok 原始资源独立订阅。初次建立两段分流机制。
- **V1.9**：83份上游规则源，21,356条聚合规则；统一业务策略组命名，并行发布不覆盖 V1.8。
- **V1.10**：105份上游规则源，22,019条聚合规则；新增跨境购物和海外音乐策略，用户完成真机测试。
- **V1.10.1**：在保持已发布规则不变前提下增加安全审计报告、约每三日检查上游的定期工作流及 PR 回归测试。
- **V1.10.2**：增加规则类型、域名后缀/关键词/通配符、CIDR 网段覆盖候选、优先级审核与差异报告，**不自动删除或变更任何规则**。

以上是版本里程碑；具体到每次已提交的版本，参见 GitHub 的 [提交历史](https://github.com/wonidie66/qx-rule-aggregator/commits/main/) 与对应 [Actions 运行历史](https://github.com/wonidie66/qx-rule-aggregator/actions)。V1.10 的后续实质更新会写入 [持久日志](../reports/history/v1.10/updates.md)。

## 维护约定

1. **发布**：只由 V1.10 稳定工作流（`.github/workflows/update-v110.yml`）生成最新两份规则。旧版工作流删除，旧版文件保留并停止更新。
2. **变更**：规则源或策略调整走 PR，先跑回归测试，再运行稳定更新；对重叠、误分流通过报告和真机日志确认后再修改。
3. **历史**：每次**产生实质文件变更并成功发布**的 V1.10 更新，在 `reports/history/v1.10/` 保存独立 Markdown 快照、追加索引；没有变化的计划检查不写入虚假的版本日志。
4. **回退**：不要删除旧版的两份 .list 文件及其审计报告，手机端可切回备份配置。历史快照及 Git 提交可协助复原规则和指标。
5. **安全与许可**：不公开机场令牌、节点凭据、私人配置、MITM 私钥；上游许可证见根目录 LICENSE / NOTICE。

## 仅为历史保留的文件

`scripts/local_replace.py`、`templates/QuantumultX_V1.9_无证书模板.conf`、`QuantumultX_V1.8_替换片段.txt` 及旧版本测试/审计代码不是当前 V1.10 的更新入口，暂不删除以保留历史迁移与回归能力。
